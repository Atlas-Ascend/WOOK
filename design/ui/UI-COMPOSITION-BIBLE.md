# UI Composition Bible

The UI must read as a cartridge interface, never as a responsive webpage.

## Screen ownership

At any moment one visual mode owns the 160×144 stage:
- overworld,
- dialogue,
- inventory,
- phone,
- encounter,
- trader,
- quest complete,
- dungeon,
- minigame,
- map,
- cutscene.

No giant HTML panels may hang below the game as canonical UX.

## Dialogue
Bottom 34–42 px.
Portrait-dialogue scenes may dedicate the upper third to a portrait.
Line length and box height are authored, not browser-wrapped accidentally.

## Inventory
Full-screen takeover.
Item icon + noun + quantity + short description.
Capacity itself is comedy.

## Phone
Full-screen diegetic takeover.
Battery visible at all times.
Opening it has mechanical cost when appropriate.

## Encounter
Dedicated composition, large encounter subject, verbs instead of generic ATTACK/MAGIC.

## Quest complete
Ceremonial. Finding Crocs receives artifact-level gravitas.

## Mobile wrapper
Touch controls exist outside the canonical 160×144 stage, never overlapping it.
They are a transport affordance, not part of the in-world UI.
