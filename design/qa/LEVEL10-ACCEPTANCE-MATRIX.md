## Hard gates
- no clipped scene titles
- no HUD/dialogue collisions
- no quest double-fire
- no player trap after UI takeover
- no HTML panels masquerading as game UI
- native web export boots
- ROM file exists and hashes
- GitHub remote SHA equals local release SHA
- GitHack returns HTTP 200
- Vercel production URL returns success if authenticated
- Cloudflare Workers deployment returns success if authenticated
