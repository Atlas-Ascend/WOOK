# 1992 Studio Master Plan

## Premise

Pretend it is 1992. The team has $3M, an executive mandate to ship one cult cartridge, and no permission to hide unfinished composition behind modern responsive UI.

### Department model

**Executive / Creative — $250k**
- Executive producer
- Creative director
- Lead writer / comedy editor
- Production manager

**Engineering — $760k**
- Lead engine programmer
- Gameplay programmers
- Tools/build programmer
- save-state/system programmer
- performance / memory specialist

**Art / Animation — $900k**
- Art director
- lead pixel artist
- character artist
- environment/tile artist
- UI artist
- animator
- technical artist

**Design / Narrative — $420k**
- lead game designer
- level designers
- quest designer
- narrative designer
- encounter/minigame designer

**Audio — $220k**
- composer
- sound designer
- implementation support

**QA / Compatibility — $250k**
- QA lead
- gameplay QA
- regression tester
- save-state tester
- hardware/browser matrix testing

**Contingency / mastering / marketing artifact — $200k**

Total planning envelope: approximately $3M.

## Studio operating doctrine

Every discipline works against the same Golden Scene.

No department is allowed to call its contribution complete in isolation:
- art must survive movement and collision,
- UI must survive real dialogue lengths,
- quests must survive reload,
- animation must survive palette/tile budgets,
- comedy must survive repeated play,
- build engineering must return reproducible artifacts,
- QA must prove the public binary/web output, not merely source presence.

## Vertical quality escalation

**Pre-alpha:** movement and state.
**Alpha:** all required systems.
**Beta:** full campaign content.
**Content complete:** no placeholder art/dialogue.
**Master candidate:** no known progression blockers; presentation at visual-contract target.
**Gold:** ROM + web + hashes + publication proof.
