# WOOK-C0-HANDSTAND-DAN-001

## Mission

Advance C0 beyond the initial Papa/Sniffany/raccoon packet by adding Handstand Dan as a real native GB Studio character with his own source-generation contract, stable identity, avatar, actor binding and optional campground interaction.

## Frozen inputs

- existing native GB Studio 4.3.2 factory;
- current Questionable Campground scene;
- current Papa Wook/Sniffany/raccoon character architecture;
- C0 map/state/SDLC contracts.

This packet does not reinstall or recreate the proven toolchain.

## Source production

`tools/generate-handstand-dan.py` deterministically produces:

- six-frame four-shade source sheet;
- native avatar source;
- signature handstand frames.

This is a reproducible engineering source, not final visual qualification. Future hand-authored art may replace the pixels while preserving stable resource IDs.

## Native implementation

`bash scripts/implement-c0-handstand-dan-001.sh`

The packet:

1. verifies the existing native project;
2. generates Handstand Dan source art;
3. promotes source into native sprite/avatar locations;
4. clones the proven animated sprite-resource grammar;
5. creates the Handstand Dan sprite `.gbsres`;
6. creates avatar `.gbsres`;
7. creates the campground actor resource;
8. adds optional authored dialogue;
9. writes a machine-readable implementation manifest;
10. performs static resource-graph QA;
11. compiles native web;
12. compiles the ROM;
13. writes a proof receipt.

## Interaction law

Handstand Dan is optional in C0. His first challenge can increase affinity/reward state later, but it cannot block Crocs, Sniffany, raccoon resolution, or the GA exit.
