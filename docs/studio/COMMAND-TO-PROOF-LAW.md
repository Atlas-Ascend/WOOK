# Command-to-Proof Law

The campaign may report these states independently:

- SOURCE_PASS
- GOLDEN_SCENE_PASS
- GB_STUDIO_SOURCE_PASS
- GB_STUDIO_CLI_PASS
- GB_STUDIO_NATIVE_WEB_PASS
- GB_STUDIO_ROM_PASS
- GITHUB_PASS
- GITHACK_PASS
- VERCEL_PASS
- CLOUDFLARE_PASS
- VISUAL_CONTRACT_PASS
- RECEIPT_PASS

`WOOK_V4_FULL_COMMAND_TO_PROOF=PASS` requires every required production lane to be green.

If authentication prevents Vercel/Cloudflare deployment, the campaign records AUTH_REQUIRED rather than fabricating success.
